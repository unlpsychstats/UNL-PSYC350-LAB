A few reminders about tables

Abbreviations:

  • Explain table abbreviations in the table caption or note section except for stats related abbreviations such as “n”, “p”, “SE”, “SD”, “OR”, “CI”, and “M”.

Column headers:

  • Make sure to give each table column a header.
  • Put column headers such as N, M, SD, df, and p in italics.
  • Do not use a column header called “Sig.” or “Significance”, rather use “p” in italics as the column header.
  • When you report CI you need to label the columns “Lower limit” and “Upper Limit” or “LL” and “UL” and then explain the abbreviation in the table note section, note the APA manual 7th ed. For example, tables 7.16 and 7.17 (pp. 219-220) on ideas for reporting CI.

Other:

  • Avoid using scale/questionnaire names in tables. In general, leave scale names out of all sections except the measurement section. Report the concept(s) you are measuring (e.g., stress, anxiety). The exception to this rule is if you are specifically talking about the scale(s) in question (e.g., DASS) rather than the concepts it measures.
  • In general, remove all vertical lines.
  • In general, remove all horizontal lines except the first two and the last. There are some exceptions as per the tables shown here below.
  • No need to report “* p < .05. ** p < .01. ***p < .001.” or any asterisks in a table that already reports exact p values in a p value column.
  • Note that p values cannot be zero thus replace “.000” with “<.001”.
