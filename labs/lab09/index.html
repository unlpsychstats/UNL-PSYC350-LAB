Lab 09: Project Analyses

Selecting appropriate statistics and running analyses for the class research project.

Preparation

Use a computer with SPSS and have your project materials ready.

Lab Overview

Learning objectives

  1. Practice selecting statistics and running project analyses.

  2. Select an appropriate statistical test based on the research question and the types of variables involved.

  3. Run and report project analyses in APA format.

How to use the Answer Checker!

  1. Type your answer into each blank box. Round to 2 decimal places where appropriate.
  2. Select your choice from the dropdown menu for interpretability
  3. The box will turn green if your answer is correct
  4. The box will turn red if your answer is incorrect - try again!
